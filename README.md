# Table 3 – Baseline Model Results (LiTS 2017)

This repository contains the result files corresponding to **Table 3** of the manuscript:

> **CLA-ResUNet: Continuous Learning Automata for Small Liver Tumor Segmentation in CT Images**

## Description

The uploaded files contain the segmentation results of the baseline models evaluated in:

**Table 3. Tumor and Liver Dice Scores of Baseline Models in Stage 3 (100 epochs with Tversky Loss + Classic Learning Automata) on LiTS 2017 tumor-containing slices.**

A total of **13 result files** are provided, corresponding to the evaluated baseline models used in the manuscript.

## Dataset

- Dataset: LiTS 2017 (Liver Tumor Segmentation Challenge)
- Evaluation: Tumor-containing CT slices
- Training Stage: Stage 3
- Training Epochs: 100
- Loss Function: Tversky Loss
- Learning Strategy: Classic Learning Automata (LA)

## Purpose

These files are provided to improve the transparency and reproducibility of the experimental results reported in the manuscript.
